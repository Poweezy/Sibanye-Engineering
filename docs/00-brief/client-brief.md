# Client Brief — Sibanye Engineering Solutions Website Redesign (archived 2026-10-21)

Issued by the client to Analytical Sigma (Pty) Ltd as lead digital agency. Archived verbatim
(summarised where repetitive) as the governing scope document.

## Mission

Deliver a distinctive, high-quality corporate website for Sibanye Engineering Solutions, taking
inspiration from the strategic clarity, strong storytelling, design discipline and case-study
presentation of https://www.ander.group/ — **without copying** Ander Group's proprietary
designs, text, branding or exact layouts.

## Phases

1. **Audit & discovery** — inspect repository, website, framework, assets, brand files,
   deployment setup and content; do not replace architecture before evaluating it. Report
   architecture/constraints, reusable components, content/asset gaps, proposed sitemap,
   visual direction, risks, implementation plan.
2. **Design** — original visual identity using approved SES brand assets: typography, colour
   tokens, spacing, grid, image treatment, interaction patterns, responsive behaviour.
   Prioritise engineering credibility, project imagery, clean layouts, strong typography,
   whitespace, purposeful animation, clear enquiry journey.
3. **Implementation** — build on the existing repository architecture: homepage, company
   profile, services, sectors, project portfolio, case-study pages, leadership, capabilities,
   approach, contact details, capability-statement download, WhatsApp integration,
   project-enquiry form. Responsive, accessible, secure, performant, maintainable.
4. **Content integrity** — proposal + client-approved capability statement are the only source
   material. Never invent project values, client relationships, outcomes, staff qualifications,
   registrations or testimonials. Flag missing information, image permissions, unapproved logos.
5. **Quality assurance** — routes, navigation, responsive layouts, form validation and
   submission, downloads, contact links, accessibility basics, SEO metadata, image
   optimisation, security configuration, production build. Fix implementation defects;
   document unresolved issues; distinguish automated vs manual testing.

## Commercial constraints

- Development: **E9,500 once-off**
- Managed hosting & care: **E2,500 per year**
- Delivery: **3–4 weeks**, subject to timely content and approvals
- Hosting compatible with the agreed deployment environment; initial scope lean and maintainable
- AI assistant, careers portal, advanced project search, engineering insights = **future
  enhancements**, not initial scope

## Working rules

Specialist agents in sequence; incremental work; report decisions, changed files, test results
and blockers after each stage; no deployment, paid services or material architecture changes
without approval; start with the repository audit — no generic templates.
